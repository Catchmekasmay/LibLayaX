## 🧠 What Is LibLayaX?

LibLayaX is a local AI engine for applications. It helps software make fast decisions on your own computer without sending your data to a remote server and without asking you to install Python. Think of it as a behind-the-scenes helper that lets an application understand information, classify it, and make structured choices quickly.

The project is a shared library and C API built on laya.cpp. In plain terms, it is a ready-made component that software can use to run the Laya typed-decision model directly inside the application. It is designed for Windows, Linux, and macOS, on common 64-bit systems, with support for CPU or GPU use. It is also an open-source alternative to Jev.

LibLayaX is useful when you want local AI decisions that are fast, private, and self-contained. Because it runs in-process, the application does not need a separate server. Because it does not need Python, there is no extra language setup for you to manage. The goal is simple: make local AI decisions easier to use inside real applications.
